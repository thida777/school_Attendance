1. Purpose and scope

This plan checks that every finished page of the website works as designed, that each role sees only what it may see, and that the attendance rules are applied the same way on the website and in the API.

Tested (finished)

  • Login, logout, roles (Admin / Teacher), English and Khmer, light and dark theme
  • School data: Students, Classes, Subjects, Teachers, Parents, Teaching Assignments
  • Take Attendance (4 steps), Attendance Monitoring / History
  • Corrections and Audit Log (24-hour rule, requests)
  • My Classes (teacher), Profile with profile photo
  • Interface: calendar date picker, modern dropdowns, page numbers without reload
  • API v1 for the Android app

Not tested yet (planned for Day 5–6)

  • Dashboard charts, Insights, At-Risk Students, Interventions, Reports
  • Student details and Teacher details pages
  • Alerts and Telegram / SMS messages to parents
  • Forgot password, Excel import

These pages show "Coming soon". Opening them must not give an error (test A-09).

2. Before you start

2.1 Start the system

  1. Start WAMP and wait until its icon is green (MySQL on port 3306 must run).
  2. Open PowerShell in D:\Project\Student_Attendance_Analytics.
  3. Optional, start from clean data (deletes all attendance and changes made before, then creates the demo school again): 
    php artisan migrate:fresh --seed
  4. Build the styles and scripts once: npm run build
  5. Start the server: php artisan serve and open http://127.0.0.1:8000 in Chrome.
Test on a school day (Monday to Saturday). The timetable has no lessons on Sunday, so the Take Attendance tests in group I need a weekday. Use two browsers (or one normal and one private window) so you can be logged in as admin and as a teacher at the same time.

K. Corrections and Audit Log (24-hour rule)

Helper to test "after 24 hours" without waiting one day. Run this once in PowerShell (in the Laravel folder). It makes the newest lesson look 25 hours old: 
php artisan tinker --execute="$s = App\Models\AttendanceSession::latest('id')->first(); $s->forceFill(['created_at' => now()->subHours(25)])->save(); echo $s->id;"
Only use it on test data.
