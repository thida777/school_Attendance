1. Purpose and scope

This plan checks that every finished page of the website works as designed, that each role sees only what it may see, and that the attendance rules are applied the same way on the website and in the API.

Tested (finished)

  • Login, logout, roles (Admin / Teacher), English and Khmer, light and dark theme
  • School data: Students, Classes, Subjects, Teachers, Parents, Teaching Assignments
  • Take Attendance (4 steps), Attendance Monitoring / History
  • Corrections and Audit Log (24-hour rule, requests)
  • My Classes (teacher), Profile with profile photo
  • Interface: calendar date picker, modern dropdowns, page numbers without reload
  • API v1 for the Android app
  • Dashboards (admin, teacher), Insights, At-Risk Students, Student details
  • Interventions (follow-ups with before / after rate), Reports (Excel and printable PDF), Teacher details
  • Parent messages by Telegram (automatic absence alerts and messages written by staff)
  • Forgot password by Telegram code, Khmer form errors
  • The online site and installing the Android app (APK)

Not in this plan

  • Every screen of the Android app in detail (group U checks installation and the main flow only)
  • Real SMS: the school has no SMS provider yet, so SMS messages are saved as a demo and marked "Demo (not sent)"
  • Importing students from Excel (not built)
  • Load testing with many users at once

Every page in the menu is finished; none shows "Coming soon" any more (test A-09).

2. Before you start

2.1 Start the system

  1. Start WAMP and wait until its icon is green (MySQL on port 3306 must run).
  2. Open PowerShell in D:\Project\Student_Attendance_Analytics.
  3. Optional, start from clean data (deletes all attendance and changes made before, then creates the demo school again): 
    php artisan migrate:fresh --seed
  4. Build the styles and scripts once: npm run build
  5. Start the server: php artisan serve and open http://127.0.0.1:8000 in Chrome.
Or test the online site (no setup): https://demohs-attendance.alwaysdata.net. It has its own copy of the data, so changes made online do not appear on the computer, and the other way round. The online password is given by the project team; it is not written here because the site is public.
Telegram (groups S and T). Parent messages and password codes are really sent only when TELEGRAM_BOT_TOKEN is set in .env. Link your own Telegram first: open the school bot, press Start, run php artisan telegram:chats, and put your chat ID on one parent (Parents → Edit) and on Pen Sovann (Teachers → Edit). Without a token, everything works in demo mode.
Test on a school day (Monday to Saturday). The timetable has no lessons on Sunday, so the Take Attendance tests in group I need a weekday. Use two browsers (or one normal and one private window) so you can be logged in as admin and as a teacher at the same time.
