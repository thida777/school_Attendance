5. Questions the committee may ask

QuestionShort answer
Why simple rules and not machine learning?Teachers must be able to check why a student is flagged, and one term of data is too little to train and test a model fairly. The rules are written in one class and covered by tests. After a full year of real data, a model can be compared against the rules.
How do you know the thresholds (70%, 80%, 90%) are right?They are a reasonable starting point, the same scale everywhere in the system, and easy to change in one place. Real validation needs a pilot term in a school, which is the first item of future work.
Is the data real?No. It is generated for a model school with a fixed seed, so results can be repeated, and it contains known patterns on purpose. No real student data was used.
How is the data kept safe?Only two roles can log in, and the role is checked on every page and API address. Passwords and reset codes are stored hashed. Login and codes have try limits. The online site uses HTTPS with error details hidden. Every attendance change is in the audit log.
What if there is no internet at the school?The website can run on a school computer or local network (it runs the same way on the laptop). Telegram messages need internet: a message that cannot be sent is saved as Failed, with the reason, and staff press Resend when the connection is back.
Why Telegram and not SMS?Telegram is free, supports Khmer text well and tells the system whether the message was delivered. SMS needs a paid provider; the system already has an SMS channel in demo mode, ready for a gateway.
Do parents agree to receive messages?Yes: a parent receives Telegram messages only after opening the school bot and pressing Start themselves.
What if a teacher forgets to take attendance?The dashboard shows “Not recorded today”, Reports show lessons recorded against the timetable, and Teacher details show each teacher’s missing lessons.
Why the 24-hour rule?A teacher can fix a mistake quickly, but old records cannot change silently: after 24 hours a change needs the admin’s approval, and every change is logged.
How was it tested?126 automatic tests (631 checks) that all pass, and a written test plan with 152 manual cases in 21 groups.
How much would it cost a school?The demo runs on a free hosting plan and Telegram bots are free. A real school would need a small paid hosting plan, and SMS would cost per message. [Add a price only if you have checked one.]
How would a school start using it?The admin enters classes, subjects, teachers, students and parents on the website (Excel import is future work), sets the timetable, and teachers install the app.
