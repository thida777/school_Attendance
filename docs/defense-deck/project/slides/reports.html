Reports

Any period, class or subject, as Excel or PDF

On screen

Rate and change, lessons recorded against the timetable, absences by subject, summary by class.

Excel

One row per student, with absences by reason. Khmer names stay readable.

PDF for the principal

A printable A4 report with signature lines. Printed by the browser, so Khmer letters stay correct.

The Reports page answers questions for any period, class and subject: the average rate and its change, how many timetable lessons were really recorded, and where absences happen. It exports to Excel with one row per student and the reasons, and to a printable A4 report for the principal with signature lines. A technical point: PHP PDF libraries often break Khmer letters, so the PDF is printed by the browser, which shapes Khmer correctly. There is also a Teacher details page with each teacher's lessons recorded and the attendance in their lessons.
