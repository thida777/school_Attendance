The architecture has one server. Both the website and the Android app talk to the same Laravel application, the app through a REST API with token login. The important design choice: every business rule lives in one service class, so the website and the app can never disagree. For example AttendanceRecorder holds the attendance rules, RiskAnalyzer the risk levels. Data is in MySQL locally and MariaDB online, and Telegram is used for parent messages and password codes.
