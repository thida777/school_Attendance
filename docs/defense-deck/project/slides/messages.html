Real message received from the system on 22 November 2026

Parents in Cambodia use Telegram every day, so the system uses a Telegram bot. When a student reaches three school days absent in a row, the parent gets one message automatically, whether the teacher used the website or the app. Staff can also write a message from the student page; the text starts with this month's attendance. New: under the automatic message the parent has three buttons. Sick or family matter writes the reason on those absences; please call me opens a phone-call follow-up for the homeroom teacher. Only that parent can answer, once. Every message and answer is logged, with Delivered, Demo or Failed and a Resend button.
