Parents in Cambodia use Telegram every day, so the system uses a Telegram bot. When a student reaches three school days absent in a row, the parent gets one message automatically, whether the teacher used the website or the app. Staff can also write a message from the student page; the text starts with this month's attendance. Every message is logged as Delivered, Demo or Failed, with a Resend button.
