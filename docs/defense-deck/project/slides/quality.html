Testing

Security

The role is checked on every page and API address; teachers see only their classes.

Passwords and reset codes are hashed; login and codes have try limits.

HTTPS online, error details hidden, and an audit log of every change.

Quality was checked in two ways. There are 129 automatic PHPUnit tests with 653 checks; they cover the risk rules, the 24-hour rule, the reports, the Telegram messages with a fake server, and every API address the app uses. They all pass. My written test plan has 155 manual test cases in 22 groups, from login to installing the APK. For security: the role is checked on every page and API route, passwords and password reset codes are stored hashed, login and reset codes have try limits, and the forgot password page gives the same answer for every phone number, so nobody can test which accounts exist.
