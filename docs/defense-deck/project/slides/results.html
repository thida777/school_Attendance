Demo data generated for a model school with fixed rules, so the results can be repeated. No real student data was used.

To test the analytics on realistic data, I generated a full term for a model school: 42 students in 6 classes, every lesson from the 1st of September to the 22nd of November, more than 13 thousand attendance records. The generator uses a fixed random seed, so the results can be repeated, and it includes known patterns on purpose, such as a student who is often absent and a class whose attendance falls. The system found them: attendance this month is 93.2 percent, 6 students are flagged, 1 Critical and 5 High. I want to be clear: this is demo data, not real students.
