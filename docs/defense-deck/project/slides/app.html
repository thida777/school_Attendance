Android app for teachers

The same system in the teacher’s pocket

Built in Java

Android Studio, XML layouts, Retrofit for the API.

Same rules, same data

A lesson marked in the app appears on the website at once.

Khmer, dark mode, Telegram reset

Forgot password: a 6-digit code from the school bot.

Teachers mostly use the Android app. It is written in Java with XML layouts, as taught in class, and uses Retrofit to call the API. Because the rules live on the server, the app and the website always agree: a lesson marked in the app appears on the website at once. The app works in Khmer and English, has a dark mode, and a teacher who forgets the password gets a six-digit code from the school's Telegram bot. The APK is signed, so new versions install as an update.
